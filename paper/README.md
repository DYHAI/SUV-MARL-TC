# Paper

This directory is the working copy for the final manuscript.

## Main files

- `main.tex`: manuscript source.
- `main.pdf`: rendered manuscript.
- `main.bib`: bibliography file used by `main.tex`.
- `figures/`: all figures, including regenerated PDF/PNG pairs.
- `../code/analysis/`: scripts that regenerate result tables and figures.

All tables are embedded directly in `main.tex`; a separate `tables/` directory
is not required.

## Compile

```bash
(cd paper && tectonic main.tex)
```

From the repository root, the main results are generated by:

```bash
python -m code.analysis.aggregate_surface_vmax_comparison
python -m code.analysis.aggregate_underwater_method_ablation
python -m code.analysis.make_surface_control_ablation_table
python -m code.analysis.make_fig2_surface_subsurface_observation
python -m code.analysis.make_traditional_planner_renderings
```

The first script requires the complete ten-seed matrix for both 12 and
20 m/s. The second uses the completed ten-seed underwater matrix.

## Final ten-seed result

The complete 12/20 m/s matrix contains 400 seed-level evaluations:
4/8/12/16 SUVs x seeds 0--9 x five deployment radii x two speed limits.
The 20 m/s policy has the lower mean tracking error in all 20
fleet-size/radius comparisons. Averaged over the four fleet sizes, its final
tracking error is 31.9, 37.9, 63.0, 89.1, and 110.5 km lower than that of the
12 m/s policy at 100, 200, 400, 600, and 800 km. The 12 m/s policy instead uses
83.4--220.1 km shorter paths on average and has lower mean speed, exposing the
intended efficiency--tracking trade-off.

The final underwater matrix contains seven depths, two propulsion limits, ten
active-policy seeds, and paired random-control and passive-drift baselines.
Active IPPO improves configuration-mean experienced current speed by
2.2--4.6%, increases geometric coverage by 3.09--5.68 times, and increases
current-weighted coverage by 2.87--4.99 times relative to passive drift.

## Classical planner comparison

Table 4 in the manuscript compares parameter-sharing IPPO with potential-field,
receding-horizon A*, lawnmower-coverage, and information-greedy planners on the
same 500-TC train/test split. Surface results cover all 40
fleet/speed/deployment configurations and 768 test segments. Subsurface results
cover seven depths, both propulsion limits, and 500 paired episodes per
setting.

Baseline code is under `../code/baselines/`, and the corresponding summary and
paired-test files are under `../results/baselines/`:

```bash
../results/baselines/surface_all_methods_summary.csv
../results/baselines/underwater_all_methods_summary.csv
../results/baselines/surface_pairwise_tests.csv
../results/baselines/underwater_pairwise_tests.csv
```
