# Results

- `surface/`: ten-seed surface summaries, raw metrics, paired tests, and the
  TC translation-speed envelope.
- `underwater/`: seven-depth strategy summaries and reports.
- `baselines/`: traditional-planner summaries and paired tests.
- `formation/`: ring/line/grid matrix summary.

These are final processed results used by the manuscript. Intermediate model
checkpoints, logs, and raw evaluation rows are generated under `runs/` and are
not tracked.
